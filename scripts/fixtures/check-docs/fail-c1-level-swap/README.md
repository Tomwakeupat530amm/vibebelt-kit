# Bộ kit mẫu

README mẫu cho `scripts/check-docs.mjs --self-test`.

```bash
curl -fsSL https://raw.githubusercontent.com/example-owner/example-kit/main/install.sh | bash
```

## Ba ví dụ

Bạn nói: "Thêm một trang." Bộ kit làm: lập kế hoạch cho trang rồi mới xây.
<!-- vibecoder-top:end -->

### Bắt đầu nhanh

<!-- quick-start:start -->
## 1. Cài đặt

Mở **terminal** và dán lệnh ở trên. Bạn cần **Node.js** và **Git**.

### 2. Bắt đầu

Nói `Run vb-setup`. Một **agent** viết **plan** trước khi sửa bất cứ thứ gì.
<!-- quick-start:end -->

## Bảng thuật ngữ

<!-- glossary:start -->
| Thuật ngữ | Nghĩa |
|---|---|
| **terminal** (cửa sổ dòng lệnh) | Cửa sổ để gõ lệnh. |
| **Node.js** | Chạy các script nhỏ của bộ kit. |
| **Git** | Lưu lịch sử của mọi thay đổi. |
| **agent** (trợ lý AI) | Một trợ lý AI làm một việc. |
| **plan** (kế hoạch) | Danh sách thay đổi được viết ra. |
| **validate** (kiểm tra) | Bước kiểm tra kế hoạch. |
| **hook** | Một script nhỏ tự chạy. |
| **skill** (kỹ năng) | Một bộ hướng dẫn được lưu sẵn. |
| **phase** (bước) | Một bước của quy trình. |
| **gate** (cổng kiểm tra) | Điều kiện phải đạt trước. |
| **commit** | Một bản lưu trong Git. |
| **branch** (nhánh) | Một hướng làm việc riêng trong Git. |
| **WSL** | Linux chạy bên trong Windows. |
<!-- glossary:end -->
