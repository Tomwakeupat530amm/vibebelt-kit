# Example kit

A fixture README for `scripts/check-docs.mjs --self-test`.

```bash
curl -fsSL https://raw.githubusercontent.com/example-owner/example-kit/main/install.sh | bash
```

## Three examples

You say: "Add a page." The kit does: it plans the page, then builds it.
<!-- vibecoder-top:end -->

## Quick start

<!-- quick-start:start -->
### 1. Install

Open a **terminal** and paste the command above. You need **Node.js** and **Git**.

### 2. Start

Say `Run vb-setup`. An **agent** writes a **plan** before it changes anything.
<!-- quick-start:end -->

## Glossary

<!-- glossary:start -->
| Term | Meaning |
|---|---|
| **terminal** | A window where you type commands. |
| **Node.js** | Runs the small scripts of the kit. |
| **Git** | Saves the history of every change. |
| **agent** | An AI helper with one job. |
| **plan** | A written list of the changes. |
| **validate** | The step that checks the plan. |
| **hook** | A small script that runs by itself. |
| **skill** | A saved set of instructions. |
| **phase** | One step of the workflow. |
| **gate** | A check that must pass first. |
| **commit** | A saved snapshot in Git. |
| **branch** | A separate line of work in Git. |
| **WSL** | Linux inside Windows. |
<!-- glossary:end -->
